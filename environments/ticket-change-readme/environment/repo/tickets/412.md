# #412 — Filter `users list` by role

**Status:** open · **Assigned:** you

Operators want to narrow the directory listing to a single role.

Add a `--role <ROLE>` option to `users list`:

- `users list` → every username (unchanged)
- `users list --role editor` → only usernames whose role is `editor`

Print one username per line, sorted ascending. No other command should
change its behavior.
